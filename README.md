# enoTone — дизайн-проект

**Статус: утверждённая база дизайн-концепции, не готовый интерфейс и не код плеера.**

> **Текущее состояние:** утверждены палитра v1.3, рабочий эталон UI v1.0, 13 актуальных изображений Бандита и мастера иконки и текстового логотипа. Оригиналы этапа 2 сохранены в `assets/current/` с SHA-256; исторический набор из 10 сцен не использовать в новых макетах.

Репозиторий предназначен исключительно для дизайн-решений личного музыкального плеера **enoTone** (с визуально выделенной буквой **T**) и его енота-маскота **Бандит**.

## Что принято

- Цветовая палитра **«Глянцевый енот»**: [`tokens/colors.json`](tokens/colors.json); темы **«Графит»** и **«Фарфор»**. Предыдущая палитра в `assets/references/ui-palette-approved.jpg` — историческая.
- **Актуальный Бандит**: 13 пользовательских PNG находятся в `assets/current/mascot/v20261104/`. Старый архив из 10 сцен сохранён для истории, но **больше не является действующим референсом**.
- **Утверждённая иконка приложения v1.0:** [Бандит с поднятой лапой, указывающий на пользователя](docs/APP_ICON_APPROVED_V1.md), «Графит»/«Фарфор» × квадрат/круг. Четыре неизменных оригинала и манифест находятся в `assets/current/app-icon/v1.0/`. Готовые [технические экспорты Windows/Linux/Android и четыре векторных SVG-кандидата](docs/APP_ICON_PLATFORM_PACK_V1.md) не меняют мастер; **ни один SVG-кандидат не утверждён как художественный мастер**, adaptive icon требует проверки на устройстве.
- **Android Adaptive Color Icon v2 (кандидат):** [отдельные прозрачный передний слой Бандита и фоновый цвет темы](docs/ANDROID_ADAPTIVE_COLOR_V2.md), Android XML, 2 темы и превью разных масок. Монохромная иконка отложена. Архив в Library, аппаратная проверка на Huawei не выполнена.
- **Текстовый логотип enoTone — Wordmark Master v1.0:** [`docs/WORDMARK_MASTER_V1.md`](docs/WORDMARK_MASTER_V1.md). Выбранное пользователем округлое начертание; зеркальные `n` и `e`; две цветовые версии. В `assets/current/wordmark/v1.0/` импортированы манифест и прозрачные PNG/SVG-экспорты. Встроенный манифест помечает экспортный пакет как candidate-for-approval, что расходится с отдельным окончательным утверждением мастера; это отмечено в документации и требует независимого уточнения статуса производных.
- **UI Baseline v1.0:** [`docs/UI_BASELINE_V1.md`](docs/UI_BASELINE_V1.md) — рабочая основа 10 экранов Desktop/Android с двумя темами. [`docs/UI_BASELINE_MANIFEST_V1.json`](docs/UI_BASELINE_MANIFEST_V1.json) и [`docs/UI_SCREENSHOTS_V1.sha256`](docs/UI_SCREENSHOTS_V1.sha256) — манифест оригиналов. Все 10 PNG сохранены в `assets/current/ui-baseline/v1.0/` и сверены с SHA-256.
- Подробные правила: [`docs/DESIGN_DECISIONS.md`](docs/DESIGN_DECISIONS.md) и [`docs/ASSET_POLICY.md`](docs/ASSET_POLICY.md).

## Ограничения

- **Не изменять** какие-либо репозитории AllMusic, работающий аудиодвижок или UI: разработка интерфейса ещё не начата.
- Не перегенерировать **утверждённую иконку v1.0** и не менять высоту лапы/положение пальца, мордочку, шарф и композицию. Предыдущие иконки и SVG — только история.
- Скриншоты иконок и коллаж с маскотом — растровые оригиналы, а не SVG-модели, не компоненты Qt/QML и не готовые Android adaptive icons.
- При будущем добавлении исходников интерфейса необходима отдельная договорённость об объёме.

В `docs/CHANGELOG.md` следует регистрировать каждое новое утверждённое решение. Исходные материалы уже размещены в этом приватном репозитории; для получения полных изображений выполните восстановление из частей архива, описанное ниже.

## Исторический архив графики

В GitHub имеются исходные изображения и PNG-экспорты в составе **восстанавливаемого без потерь** набора `assets/packages/approved-assets.zip.part01` … `part05`. Части архива ограничены по размеру для загрузки через GitHub.

После клонирования проекта выполните:

```bash
python tools/restore_assets.py
```

Скрипт без сторонних библиотек восстановит **12 исторически сохранённых графических файлов** по их штатным путям `assets/`, включая прежний коллаж из 10 сцен Бандита, доску иконок и PNG-экспорты. Файлы байт-в-байт соответствуют исходникам того периода. **Не использовать старый коллаж в новых макетах:** актуальный набор из 13 PNG находится в `assets/current/mascot/v20261104/`.

**Не заменяйте восстановленные оригиналы AI-перегенерациями и не изменяйте пропорции Бандита.** Это отдельный дизайн-репозиторий; в действующие AllMusic изменения не внесены.

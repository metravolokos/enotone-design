# enoTone — дизайн-проект

**Статус: утверждённая база дизайн-концепции, не готовый интерфейс и не код плеера.**

> Внимание: первоначальные растровые референсы готовятся к пакетному переносу; до их загрузки ссылки на `assets/` могут быть недоступны.

Репозиторий предназначен исключительно для дизайн-решений личного музыкального плеера **enoTone** (с визуально выделенной буквой **T**) и его енота-маскота **Бандит**.

## Что принято

- Цветовая палитра для обеих тем (строго по референсу): [`tokens/colors.json`](tokens/colors.json), [`assets/references/ui-palette-approved.jpg`](assets/references/ui-palette-approved.jpg).
- **10 сцен Бандита**: [`assets/references/bandit-10-approved.png`](assets/references/bandit-10-approved.png) — единственный актуальный исходный лист из 10 изображений. Персонажа не перерисовывать.
- **4 иконки приложения**: [`assets/icons/originals/four-icon-board.png`](assets/icons/originals/four-icon-board.png) — исходная утверждённая доска; файлы для макетов в [`assets/icons/exports/`](assets/icons/exports/).
- Подробные правила: [`docs/DESIGN_DECISIONS.md`](docs/DESIGN_DECISIONS.md) и [`docs/ASSET_POLICY.md`](docs/ASSET_POLICY.md).

## Структура

```text
assets/
  references/          10 сцен Бандита и палитра — оригиналы
  icons/originals/     исходная доска с 4 принятыми иконками
  icons/exports/       отдельные PNG 432 и 512 пикселей
  icons/preview/       обзорная картинка

docs/
  DESIGN_DECISIONS.md  бренд, правила, утверждённые / открытые решения
  ASSET_POLICY.md      правила сохранения оригиналов
  CHANGELOG.md         история решений
  SOURCES.sha256       контрольные суммы

tokens/
  colors.json          машинно-читаемые цвета
AGENTS.md              инструкция для ИИ-агентов
```

## Ограничения

- **Не изменять** какие-либо репозитории AllMusic, работающий аудиодвижок или UI: разработка интерфейса ещё не начата.
- Никаких AI-перегенераций утверждённых изображений; не менять пропорции, морду, упитанность, шарф, реквизит и четыре иконки.
- Скриншоты иконок и коллаж с маскотом — растровые оригиналы, а не SVG-модели, не компоненты Qt/QML и не готовые Android adaptive icons.
- При будущем добавлении исходников интерфейса необходима отдельная договорённость об объёме.

В `docs/CHANGELOG.md` следует регистрировать каждое новое утверждённое решение. Этот архив можно перенести в новый приватный репозиторий GitHub без изменений содержимого.

# enoTone App Icon v1.0 — утверждённый мастер

**Дата утверждения:** 2026-11-04  
**Статус:** **APPROVED** — пользователь ответил «Принимаем» на последнюю композицию с приподнятой лапой Бандита.

## Идея и неизменяемая композиция

> Пользователь нажимает на Бандита, который в ответ показывает пальцем прямо на пользователя.

- Бандит крупный, подмигивает и улыбается, шарф кораллово-розовый.
- **Лапа с направленным на зрителя пальцем поднята высоко, крупно и отчётливо видна**, находится перед мордочкой/шарфом в композиции.
- Персонаж **выглядывает из-за нижнего края**. Никакого пустого пространства снизу между Бандитом и краем иконки. Шарф и туловище выходят за границу.
- Верхняя часть головы и уши помещаются внутри формы; изображение должно сохранять узнаваемость в квадрате и круге.
- Утверждены четыре художественных варианта **«Графит» / «Фарфор» × квадрат / круг**. Все являются отдельными оригиналами, **не надо заменять их прежними вариантами с низкой лапой или старым Бандитом**.
- Фиксируются **именно последние четыре PNG**, а не ранний SVG v2 и не другие версии генерации.
- Не перегенерировать и не менять размеры/позицию пальца, выражение морды, глаза, шарф, стилистику без отдельного решения.

## Отношение к SVG

**Критически важно:** визуально векторный стиль на изображении не означает, что файл SVG. Утверждённые четыре изображения — **растровые PNG**. Предыдущий `bandit_smooth.svg` из [BANDIT_SVG_V2.md](BANDIT_SVG_V2.md) относится к **старой композиции, где лапа ниже**. Он НЕ является SVG этого утверждённого оформления.

Чтобы получить действительно гладкий SVG **новой** иконки, нужно отдельно заняться векторизацией нового утверждённого рисунка, не меняя изображение. Не выдавать прежний SVG v2 за финальную иконку.

## Техническое продолжение — 2026-11-04

Из утверждённых оригиналов подготовлены [экспорт для Windows/Linux/Android и SVG-кандидаты](APP_ICON_PLATFORM_PACK_V1.md), без изменения исходных пикселей. Windows ICO и Linux PNG технически проверены; Android legacy PNG изготовлены, adaptive icon — **прототип**, который ещё нужно проверить на реальном устройстве.

**SVG именно новой композиции теперь существует**, но в статусе **неутверждённого технического кандидата**: автоматическая трассировка упрощает градиенты и даёт зернистость по сравнению с исходными PNG. Для приложения пока приоритетны утверждённые растровые оригиналы. Все пакеты в Library, не в GitHub.

## Следующие технические задачи (частично выполнены)

1. **Выполнено:** прозрачные геометрические маски для круглой/скруглённой формы; оригиналы нетронуты.
2. **Частично выполнено:** Android legacy icons и adaptive XML с foreground bitmap. **Не выполнено:** прозрачная отдельно выделенная фигура, monochrome, проверка на устройстве.
3. **Выполнено технически:** Windows ICO и Linux PNG. **Не проверено:** реальный вид на целевых ОС.
4. **Кандидат:** четыре SVG из новых оригиналов есть, но не соответствуют художественному качеству оригинала из-за зернистости/постеризации. Не утверждены.
5. **Не выполнено:** загрузка графических оригиналов и производных в GitHub (пока только Library).

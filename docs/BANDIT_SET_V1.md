## Файлы

- `assets/bandit/originals/` — файлы владельца **без изменений** (SHA-256 ниже).
- `assets/bandit/clean/` — те же изображения с исправленной прозрачностью, обрезанные по фигуре; для интерфейса использовать их. Пересборка: `python3 tools/clean_bandit.py assets/bandit/originals assets/bandit/clean` (байт в байт).
- `assets/bandit/clean/preview.png` — все восемь на «Графите» и «Фарфоре».

Что исправлено (персонаж не перерисовывался):
- у RGBA-файлов внутри фигуры альфа 240–254 (Бандит слегка просвечивал) → 255; шум альфы вдали от фигуры убран;
- у трёх RGB-файлов (02, 05, 06) прозрачности не было — фон-шахматка был **нарисован**; светлый фон, связанный с краем кадра, сделан прозрачным, край сглажен на 0,7 px. На тёмном фоне каймы нет (проверено).

## 2026-11-04 — словесный логотип v1.2

- Принят принцип зеркальной композиции `enoTone`: крупная и жирная центральная `T` служит осью отражения.
- Справа от `T` последовательность `one`: `o` симметрична, **`n` и `e` отражаются горизонтально** относительно обычного начертания. Это не поворот на 180°.
- Предыдущий эскиз с отражённой только `e` отмечен как промежуточный. Итоговый файл логотипа, точно соответствующий новому правилу, пока не подготовлен.

- Цвета доски относятся к новому cartoon-Бандиту, но исходные фотографии фигурки **не служат** источником графики персонажа. Референс-доска пока не загружена в GitHub; SHA-256 приведён в `DESIGN_DECISIONS.md`.

## 2026-11-04 — окончательная иконка enoTone App Icon v1.0

- Пользователь утвердил **последние 4 варианта**: «Графит» / «Фарфор», квадрат / круг, 1254×1254. Бандит **высоко поднимает лапу и показывает пальцем на пользователя**, выглядывая из-за нижнего края без отступа. Идея: пользователь тыкает в Бандита, а Бандит — в пользователя.
- Это решение **заменяет** раннюю доску из четырёх иконок и предыдущие композиции с более низкой лапой.
- Все четыре оригинальных RGB PNG сохранены байт-в-байт, SHA-256 в `docs/APP_ICON_APPROVED_V1.md`; полный пакет, сравнение, манифест и уменьшенные PNG — в Library `/enoTone Design/Icon/Approved v1.0/`.
- **SVG именно этой новой иконки не существует**: исторические SVG v1/v2 относятся к более ранней композиции. Платформенные adaptive/monochrome и ICO ещё предстоит подготовить.
- В GitHub добавлена документация, оригинальные PNG/ZIP пока в Library, в GitHub не загружены.

## 2026-11-04 — платформенные экспорты и SVG-кандидаты утверждённой иконки

- На основе четырёх окончательно утверждённых PNG созданы **Windows ICO** (16–256 px), **Linux hicolor PNG** (16–1024 px) и **Android legacy icons** (5 плотностей + круглые/обычные), с прозрачностью вне рамки.
- Для Android добавлены adaptive XML, цвета тем и тематические foreground bitmap: это **прототип** с полным фоновым рисунком в foreground, не отдельно выделенная фигура; проверка реальным лаунчером и monochrome — впереди.
- Из каждого из четырёх новых оригиналов создан свой **настоящий SVG на кривых Безье**, без встроенных растровых данных. Кандидаты **НЕ утверждены**: заметны зернистость/упрощение градиентов. Художественный эталон остаётся PNG.
- Технический документ: `docs/APP_ICON_PLATFORM_PACK_V1.md`. ZIP-пакеты и сравнения сохранены в Library: `/enoTone Design/Icon/Platform resources v1.0/` и `/enoTone Design/Icon/Approved Icon SVG Candidate v1/`; в GitHub пока только документация.

# enoTone — Bandit SVG v2: smooth Bézier tracing

**Date:** 2026-11-04  
**Status:** `CANDIDATE / AWAITING VISUAL APPROVAL`. Векторная техническая версия, **не замена оригинальному PNG** до подтверждения пользователя.

## Причина переделки

Предыдущий `docs/BANDIT_SVG_V1.md` описывает векторную мозаику из множества прямоугольников и `crispEdges`, что давало характерную «лесенку». Этот метод **не использовать** в качестве новой графики приложения.

## Новый SVG

- **Векторный мастер:** `bandit_smooth.svg`, SHA-256 `94fc9a746c2007c013ccb0d123a3db34ca3d8e6bf9e89f145141ffbd4470886f`.
- **Неприкосновенный исходник:** `милый_енот_в_коралловом_шарфе.png`, SHA-256 `b82b435286014ec28683a34c02ac3f6b4de412c1a19fd155d4eea232d38725df`.
- Основные цветовые плоскости (порядка **50 цветовых групп**) построены автоматической трассировкой с реальными **кривыми Безье**: SVG `<path d="…C…">`; не из прямоугольников, без встроенного PNG / `<image>` / data URI.
- **Прозрачный фон** основного `bandit_smooth.svg`: экспортированный PNG подтверждает, что угловой пиксель имеет alpha=0.
- Сохранены дополнительные SVG `icon_graphite_square.svg`, `icon_graphite_round.svg`, `icon_porcelain_square.svg`, `icon_porcelain_round.svg`; фоновые цвета только из `tokens/colors.json` (`#1B1A19`, `#EDE9E5`). В круглых версиях углы прозрачны.
- SVG проверены XML-парсером, независимыми PNG-экспортами 64/128/256/512 и ZIP CRC.
- Альтернатива `bandit_detailed_alternative.svg` (больше цветовых групп): для сравнения; её мелкие переходы выглядят менее чисто.

## Известные ограничения и приёмка

Автоматическая трассировка **упрощает градиенты, блики и тонкие цветовые переходы**. В отличие от первого SVG, контуры плавные и масштабируются без прямоугольной мозаики, но это **не точная ручная Bézier-отрисовка**. В увеличенном виде рисунок отличается от оригинала, поэтому:
- исходный PNG остаётся художественным эталоном;
- для пиксельно точного отображения маскота в интерфейсе пока предпочтительнее оригинальный PNG;
- для финального профессионального SVG с полной сохранностью характерных штрихов потребуется ручная работа с формами и градиентами;
- не объявлять SVG v2 окончательным фирменным мастером без оценки пользователя.

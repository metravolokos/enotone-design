# enoTone — действующие дизайн-решения

**Документ:** ETON-DESIGN-001 · **Версия:** 2.0 · **Дата:** 2026-11-13
**Статус:** сводка того, что действует сейчас. Как к этому пришли — [CHANGELOG](CHANGELOG.md). Полная история с отменёнными решениями (старый Бандит, иконка v1.0, Wordmark Master v1.0, SVG-кандидаты, архивы) — в Git до коммита `dd0c101`.

Область: персональный музыкальный плеер enoTone для Android (основная платформа) и в будущем Desktop (Windows/Linux).

## 1. Бренд

- Название — **enoTone**, всегда с заглавной **T**: `ENOT` (енот) + `TONE` (тон) с общей `T`; `ENOTONE` — палиндром.
- Маскот — **Бандит** (Bandit). Это имя персонажа, не приложения.
- Текстовый логотип — **Wordmark v2.0** (утверждён 2026-11-12): своя геометрия со скруглённой линией значков, `one` — зеркало `eno` относительно большой двухцветной `T`, «e» с раскрытым просветом. Источник — `tools/build_wordmark.py`, файлы — `assets/wordmark/v2/`. В интерфейсе — **только «Настройки» и «О приложении»**. Подробности: [WORDMARK_V2](WORDMARK_V2.md).
- В коде, заголовках и метаданных — обычная строка `enoTone`.

## 2. Иконка приложения — App Icon v2.0 (2026-11-12)

Одна иконка на фоне «Графит» `#1B1A19`, светлой версии нет. Бандит поднимается от нижнего края без отступа и указывает лапой на пользователя. На Android — adaptive icon (прозрачный foreground + цвет фона); квадрат и круг 1024 px — только для README и сайта. Собирается `tools/build_app_icon.py` из неизменного мастера `assets/bandit/masters/bandit_pointing_master_1254.png`. Monochrome отложен владельцем. Подробности: [APP_ICON_V2](APP_ICON_V2.md).

## 3. Бандит

- Действующий персонаж — мультяшный (контурный, плоская заливка) Бандит из 13 изображений владельца (плюс второй вариант позы в наушниках): оригиналы `assets/bandit/originals/` (не изменять), исправленная прозрачность `assets/bandit/clean/`.
- Форму, мордочку, маску, шерсть, шарф и реквизит не менять; не перегенерировать. Разрешены масштаб, кадрирование, маски.
- 3D-версия для интерфейса отклонена: спорит с обложками, теряется на малых размерах.
- Назначение поз по экранам, правила (один Бандит на экран; только пустые состояния, приглашения, «Настройки», плашка «Перемешать всё»; никогда в списках) и голос сообщений — [BANDIT_SET_V1](BANDIT_SET_V1.md).
- Указующий жест — только на иконке приложения, в интерфейсе не повторяется.

## 4. Палитра и стиль «Глянцевый енот» (v1.3, 2026-11-04)

Машинно-читаемый источник — [`tokens/colors.json`](../tokens/colors.json). Ассоциация — глянцевая фарфоровая фигурка: кремовый «мех», пудрово-розовый, тёмная «маска», холодный голубой блик.

| --- | --- | --- | --- | --- |
| background | `#1B1A19` | | background | `#EDE9E5` |
| surface | `#252321` | | surface | `#F8F5F1` |

| highlight | `#8FB0C2` | | — | — |

- Розовый — главный акцент; на розовых заливках — **тёмные** значки и надписи (кремовый на розовом ≈ 1,6:1).
- Голубой — только вспомогательный в тёмной теме; контрастная версия для «Фарфора» не утверждена — не вводить наугад.
- Реальные обложки не перекрашивать. Глянец — выборочно, остальной интерфейс матовый и спокойный.
- Контраст: основной текст ≈ 14,9:1 / 13,7:1, вторичный ≈ 8,0:1 / 6,1:1. Не утверждены: роли ошибок и предупреждений, disabled, фокус для розовых элементов на светлом фоне.

## 5. Типографика

**Unbounded** — крупные заголовки экранов; **Onest** — всё остальное (данные медиатеки, навигация, управление). Шрифты не заменять без отдельного решения.

## 6. Значки интерфейса — UI Icons v1 (2026-11-12)

Собственный набор из 19 значков: сетка 24, линия 2, круглые концы; контур — обычная вкладка, заливка — активная. Категория «Исполнители альбомов» подписывается **«Авторы»** в панели и **«Авторы альбомов»** в заголовке. Служебные значки вне набора — Material Symbols Rounded. Источник — `tools/build_ui_icons.py`. Подробности: [UI_ICONS_V1](UI_ICONS_V1.md).

## 7. Android UI v2 (2026-11-12)

Минимализм по простоте Apple Music, без копирования чужого оформления. Эталонные экраны — `assets/ui-screens/android-v2/`, описание и размеры — [UI_ANDROID_V2](UI_ANDROID_V2.md). Экран эталона — Huawei Nova 15 Pro: **377 × 816 dp, радиус углов ≈ 56 dp**.

Главное: нижняя панель «Домой · Песни · Альбомы · Артисты · Авторы»; без верхних кнопок «назад» (системный жест); мини-плеер с двумя кнопками; «⋮» и долгое нажатие открывают один лист действий; прокрутка всего экрана с тонкой полоской-заголовком (вариант B); «Домой» — вариант C2 с Бандитом в наушниках; «волна» у играющего трека; Бандит — только в пустых состояниях и «Настройках». Порядок переноса в приложение — [ANDROID_INTEGRATION_PLAN](ANDROID_INTEGRATION_PLAN.md).

## 8. Desktop

Рабочее направление — Desktop-часть [UI_BASELINE_V1](UI_BASELINE_V1.md) (5 экранов, обе темы); работа отложена до готовности Android. Палитра, шрифты, Бандит и логотип — общие с Android, раскладки — отдельные.

## 9. Границы

- Репозиторий только для дизайна. Код и аудиодвижки проектов AllMusic не трогать.
- Единственный источник ресурсов для приложения — этот репозиторий; приложение копирует их из `main` без изменений.
- Каждое утверждённое изменение — строка в [CHANGELOG](CHANGELOG.md) и правка этого документа. Оригиналы проверять по SHA-256.
- Никаких учётных данных и личных данных WebDAV в репозитории.

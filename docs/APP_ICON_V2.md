# enoTone App Icon v2.0 — утверждённая иконка приложения

**Дата:** 2026-11-12
**Статус:** **APPROVED** владельцем; аппаратная проверка на Huawei Nova 15 Pro ещё не выполнена.
**Заменяет:** App Icon v1.0 (`APP_ICON_APPROVED_V1.md`), платформенный пакет v1 (`APP_ICON_PLATFORM_PACK_V1.md`) и Android Adaptive Color v2 (`ANDROID_ADAPTIVE_COLOR_V2.md`). Они остаются историей.

## Почему заменена v1.0

Четыре PNG v1.0 были RGB без альфы, с фоном, нарисованным генератором (холодный `#1B1D20` вместо токена «Графит», светлый `#FEF4E7` вместо «Фарфора»). Для Android adaptive icon фигуру приходилось вырезать сегментацией, что искажало контур. Владелец предоставил отдельный мастер Бандита с прозрачным фоном, специально не обрезанный снизу, чтобы иконки собирались из него без перерисовки.

## Исходник

| Файл | Размер | SHA-256 |
| --- | --- | --- |
| `assets/bandit/masters/bandit_pointing_master_1254.png` | 1254×1254 RGBA | `b82b435286014ec28683a34c02ac3f6b4de412c1a19fd155d4eea232d38725df` |

Бандит подмигивает, улыбается, указывает лапой на зрителя, розовый шарф; фигура целиком, без фона. Исходник хранится **без изменений**.

## Решения

1. **Одна иконка, один фон — «Графит» `#1B1A19`** (`tokens/colors.json` → `dark.background`). Лаунчеры почти никогда не переключают фон иконки по теме системы, поэтому светлая версия не выпускается. Кремовый мех и розовый шарф на тёмном фоне контрастнее.
2. **Форму задаёт лаунчер.** Для Android основным ресурсом является adaptive icon: прозрачный foreground + цвет фона. Квадрат и круг 1024 px — для README, сайта и каталогов, не для выбора пользователем.
3. **Композиция:** Бандит выглядывает из-за нижнего края, пустого места под фигурой нет.
   - квадрат: ширина фигуры 80 % стороны, верх ушей 7,5 % от верхнего края;
   - круг и adaptive (видимая область 72 dp из 108 dp): 74 % и 8,5 %, чтобы кулак и шарф не срезались маской.
4. **Пиксели персонажа не изменяются.** Единственная техническая правка: в исходнике внутри фигуры альфа 249–254 (персонаж слегка просвечивал) → приводится к 255; альфа < 6 → 0. Края исходника чистые, без белой каймы.
5. **Monochrome-слой** (тематические значки Android 13+) по-прежнему отложен.

## Воспроизведение

```bash
python3 tools/build_app_icon.py assets/bandit/masters/bandit_pointing_master_1254.png assets/icons/v2.0
```

Зависимости: Pillow, numpy. Скрипт пересобирает все файлы, кроме превью, байт в байт (проверено 2026-11-12). Параметры композиции — в начале скрипта.

## Не проверено

- Вид на рабочем столе Huawei Nova 15 Pro: какую маску накладывает лаунчер, нет ли обрезки ушей.
- Windows ICO и Linux-набор для v2.0 не собирались (Desktop-версия плеера пока не разрабатывается).

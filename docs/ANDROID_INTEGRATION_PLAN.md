# План переноса дизайна Android v2 в приложение enoTone-android

**Дата:** 2026-11-12 · **Статус:** утверждено владельцем.
Этот репозиторий — **единственный источник ресурсов** (иконка, значки, логотип, Бандит, токены). В приложение они попадают только копией из `main`, без правок; правки — через генераторы в `tools/` и PR сюда.

## Порядок слияния

1. **D0.** PR этого репозитория — строго по порядку: **#7** (иконка v2.0) → **#8** (UI Icons v1) → **#9** (Бандит) → **#10** (Wordmark v2.0). Каждый основан на предыдущем.
2. **D1 (= M6-0/R в enoTone-android).** Ресурсы в `:app`: иконка + манифест, `ic_eno_*`, `enotone_wordmark` + `wordmark_colors`, Бандит (12 поз, WebP 720 px, `drawable-nodpi`), `eno_colors` из `tokens/colors.json`, шрифты Onest/Unbounded. Экраны не меняются; видна только новая иконка.
3. **Ждём** M6-0/4b, 4c и **M6-0/5** (экраны в `:feature:*`, ViewModel, stateless Composable).
4. **D2.** Дизайн-система в коде: тема (цвета, Onest/Unbounded, радиусы) и базовые компоненты; новый ADR заменяет ADR-0073.
5. **D3.** Каркас: плавающая нижняя панель «Домой · Песни · Альбомы · Артисты · Авторы», закреплённый мини-плеер, прокрутка (вариант B), без верхних кнопок «назад»; «Домой» C2.
6. **D4.** Медиатека (нужны M6-0/6 — длительность, M6-0/7 — поиск/сортировка). **D5.** «Сейчас играет» с буферизацией. **D6.** Бандит в состояниях и «Настройки» (нужны M6-0/4b, 4c). D4–D6 — параллельно, отдельными PR.

## Где эталоны

- Вид экранов: холст «Дизайн аудиоплеера «Енот»» (claude.ai), ряды «Android v2 …».
- Поведение и правила: документ владельца `DECISIONS_android_v2_ui.md` и `SPEC_now_playing_buffering.md` (проект claude.ai «enoTone Android AudioPlayer»); после D1 — копия плана в `enoTone-android/docs/DESIGN_PLAN.md`.
- Ресурсы и их правила: `docs/APP_ICON_V2.md`, `docs/UI_ICONS_V1.md`, `docs/WORDMARK_V2.md`, `docs/BANDIT_SET_V1.md`, `tokens/colors.json`.

## Правила

- Не перерисовывать и не перегенерировать ресурсы в приложении; логотип не набирать шрифтом.
- Изменение интерфейса — сначала холст и решения владельца, потом код.
- В описании каждого PR приложения — SHA коммита этого репозитория, из которого взяты ресурсы.

## Допустимо

- Копирование без изменений, расположение, масштабирование для интерфейса, экспорт PNG в разные размеры, аккуратные маски для удаления фона при сохранении всех пикселей персонажа и предметов.
- Новые композиции UI вокруг этих активов; при необходимости содержимое сцены можно вписать как единый прямоугольный баннер на подходящем фоне.
- Техническая подготовка платформенных ресурсов после отдельной проверки.

## Запрещено без согласования

- Менять форму тела, упитанность, выражение морды, текстуру шерсти, маску вокруг глаз, шарф, книгу, стойку, наушники и подушку.
- Перегенерировать сцену на базе AI, выдавая это за тот же рисунок; размывать/додумывать части изображений при увеличении.
- Подменять четыре утверждённые иконки ранее обсуждавшейся плоской мордочкой или другой стилизацией.

## Известные ограничения

- Архивный коллаж с десятью сценами — **1536×1024 px общий лист**; это не актуальный набор Бандита.
- Вырезки `_512.png` не содержат новых деталей относительно 432×432 PNG.
- **Текущий статус:** [технический набор Windows ICO, Linux PNG, Android legacy + adaptive prototype и SVG-кандидаты](APP_ICON_PLATFORM_PACK_V1.md) подготовлен из утверждённых последних четырёх PNG. Windows ICO **готовы**, Android adaptive ещё не прошёл проверку и включает baked background в foreground bitmap, monochrome icon отсутствует. SVG-кандидаты настоящие векторные, но из-за зернистости и упрощённых градиентов **не утверждены** как художественный мастер. Ранее созданные [SVG v1](BANDIT_SVG_V1.md)/[v2](BANDIT_SVG_V2.md) — старая композиция, не использовать.
- В случае необходимости истинного высокого разрешения нужно отдельно согласовать стратегию; запрещено менять героя ради разрешения.

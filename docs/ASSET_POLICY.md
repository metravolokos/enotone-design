# Политика графических ресурсов

## Действующие источники

| Ресурс | Где | Как меняется |
| --- | --- | --- |
| Бандит — оригиналы владельца | `assets/bandit/originals/` | никак: байт в байт, SHA-256 в `BANDIT_SET_V1.md` |
| Бандит — исправленная прозрачность | `assets/bandit/clean/` | только `tools/clean_bandit.py` |

## Допустимо

- Масштабирование, кадрирование свободного фона, маски, размещение, экспорт в нужные форматы и размеры.
- Исправление прозрачности, не меняющее пикселей персонажа и реквизита.
- Новые композиции интерфейса вокруг утверждённых ресурсов.

## Запрещено без решения владельца

- Менять форму тела, мордочку, маску, шерсть, шарф и реквизит Бандита (книгу, наушники, подушку, стойку, кресло).
- Перегенерировать Бандита с помощью ИИ и выдавать за тот же рисунок; «додумывать» детали при увеличении.
- Править руками файлы, которые собирают скрипты.
- Возвращать отменённые ресурсы (старый коллаж из 10 сцен, иконку v1.0, Wordmark Master v1.0, SVG-кандидаты) — они есть только в истории Git до коммита `dd0c101`.

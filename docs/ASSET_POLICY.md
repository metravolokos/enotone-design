# Политика графических ресурсов

## Принятые источники

1. **Актуальный персонаж Бандит:** 13 отдельных PNG, присланных пользователем 2026-11-04, находятся в `assets/current/mascot/v20261104/` и сверяются по `assets/current/CHECKSUMS.sha256`. Старый `assets/references/bandit-10-approved.png` — **только исторический источник**, НЕ использовать в новых макетах.
2. **Актуальная палитра:** `tokens/colors.json` v1.3 и исходная доска `assets/current/palette/original_board.png`. Старый `assets/references/ui-palette-approved.jpg` — исторический источник.
3. **Иконка приложения:** действующий художественный мастер — только четыре последних утверждённых пользовательских PNG v1.0 в `assets/current/app-icon/v1.0/`, описанные в `docs/APP_ICON_APPROVED_V1.md`. Более ранний файл `милый_енот_в_коралловом_шарфе.png`, SVG v1/v2 и прежняя доска `assets/icons/originals/four-icon-board.png` относятся к предыдущим композициям и остаются историческими материалами. Технические SVG-экспорты утверждённых PNG и платформенные ресурсы являются кандидатами и не становятся автоматически утверждённым художественным мастером.
4. **Текстовый логотип:** `docs/WORDMARK_MASTER_V1.md` — окончательно утверждённый Wordmark Master v1.0 (отдельно от иконки).

Актуальные источники описаны выше. Старые архивы сохраняются для истории, но не отменяют последующие решения пользователя. Полный импорт проверяется командой `python3 tools/verify_enotone_assets.py` без флагов; smoke-only режим не заменяет проверку всех 37 файлов.

## **Актуальное утверждение иконки — 2026-11-04**

**Наивысший приоритет:** `docs/APP_ICON_APPROVED_V1.md` — 4 окончательно утверждённых пользовательских PNG Бандита, который указывает пальцем прямо на пользователя. Композиция обрезана нижней границей, без отступа снизу; поднятая лапа должна быть заметной. Они замещают ранние четыре иконки из доски и ранние иллюстрации с более низкой лапой.

Оригиналы и SHA-256 сохранены в `assets/current/app-icon/v1.0/` и зафиксированы в Library `/enoTone Design/Icon/Approved v1.0/`. Файлы 1254×1254 RGB, **альфа-канала нет**. SVG `bandit_smooth.svg` v2 создан из более ранней композиции и **НЕ соответствует новой утверждённой иконке**; для актуального оригинала SVG ещё не изготовлен. Новые варианты платформенных масок — отдельная задача. Никакая из технических трассировок не становится автоматически художественным эталоном.

## Допустимо

- Копирование без изменений, расположение, масштабирование для интерфейса, экспорт PNG в разные размеры, аккуратные маски для удаления фона при сохранении всех пикселей персонажа и предметов.
- Новые композиции UI вокруг этих активов; при необходимости содержимое сцены можно вписать как единый прямоугольный баннер на подходящем фоне.
- Техническая подготовка платформенных ресурсов после отдельной проверки.

## Запрещено без согласования

- Менять форму тела, упитанность, выражение морды, текстуру шерсти, маску вокруг глаз, шарф, книгу, стойку, наушники и подушку.
- Перегенерировать сцену на базе AI, выдавая это за тот же рисунок; размывать/додумывать части изображений при увеличении.
- Подменять четыре утверждённые иконки ранее обсуждавшейся плоской мордочкой или другой стилизацией.

## Известные ограничения

- Архивный коллаж с десятью сценами — **1536×1024 px общий лист**; это не актуальный набор Бандита.
- Вырезки `_512.png` не содержат новых деталей относительно 432×432 PNG.
- **Текущий статус:** [технический набор Windows ICO, Linux PNG, Android legacy + adaptive prototype и SVG-кандидаты](APP_ICON_PLATFORM_PACK_V1.md) подготовлен из утверждённых последних четырёх PNG. Windows ICO **готовы**, Android adaptive ещё не прошёл проверку и включает baked background в foreground bitmap, monochrome icon отсутствует. SVG-кандидаты настоящие векторные, но из-за зернистости и упрощённых градиентов **не утверждены** как художественный мастер. Ранее созданные [SVG v1](BANDIT_SVG_V1.md)/[v2](BANDIT_SVG_V2.md) — старая композиция, не использовать.
- В случае необходимости истинного высокого разрешения нужно отдельно согласовать стратегию; запрещено менять героя ради разрешения.

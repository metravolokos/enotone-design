# Android UI v2 — эталонные экраны

**Дата:** 2026-11-12
**Статус:** `APPROVED_REFERENCE` — утверждённый владельцем эталон раскладки Android v2 («минимализм в духе Apple Music»). Реализация в `enoTone-android` — по плану [ANDROID_INTEGRATION_PLAN](ANDROID_INTEGRATION_PLAN.md), этапы D2–D6.

Заменяет как эталон Android-часть [UI_BASELINE_V1](UI_BASELINE_V1.md) и бриф «спокойного интерфейса» от 2026-11-11 (удалён при чистке 2026-11-13, история — коммит `dd0c101`). Палитра — `tokens/colors.json` v1.3, значки — [UI_ICONS_V1](UI_ICONS_V1.md), Бандит — [BANDIT_SET_V1](BANDIT_SET_V1.md), логотип — [WORDMARK_V2](WORDMARK_V2.md).

## Экран эталона — Huawei Nova 15 Pro

| Параметр | Значение | Как получено |
| --- | --- | --- |
| Разрешение | 1320 × 2856 px | `adb shell wm size` |
| Плотность | 560 dpi (× 3,5) | `adb shell wm density` |
| Размер в dp | **377 × 816 dp** | 1320 / 3,5 × 2856 / 3,5 |
| Область приложения | 377 × 755 dp | `dumpsys display` |
| Вырез камеры | «пилюля» по центру сверху ≈ 77 × 27 dp; зона выреза по системе 79 × 45 dp | фото экрана, `dumpsys display` |
| **Радиус углов экрана** | **≈ 56 dp** (55–57 на всех углах) | измерен по фото экрана; `Display.getRoundedCorner()` у Huawei возвращает 0 |

Для сравнения: iPhone 15/16 — 55 pt при ширине 393 pt. Скругление на устройстве — плавная кривая (squircle); 56 dp — эквивалентный радиус окружности.

Все артборды нарисованы в 377 × 816 dp с радиусом 56. PNG экспортированы в масштабе × 2, каждая картинка — обе темы: слева «Графит», справа «Фарфор» (у состояний Бандита — по файлу на тему).

## Ключевые размеры раскладки

- Поля экрана — 28 dp; плавающие мини-плеер и панель — 12 dp от краёв (идут параллельно скруглению).
- «Сейчас играет»: обложка 321 dp (ширина минус поля), кнопки 64 / 84 / 64 dp с зазором 28.
- Альбом: обложка 240 dp. Сетка альбомов — 2 колонки, зазор 12 dp.
- Строки списков — 64 dp (обложка 44 dp), треки альбома — 52 dp.
- Заголовок экрана — Unbounded 600, 30 sp; заголовки секций «Домой» — Onest 600, 17 sp в одну строку; кнопки-«пилюли» — 48 dp, 15,5 sp без переноса.

**В коде размеры под этот экран не захардкоживать:** обложка считается от доступной ширины; раскладку проверять также на 360 dp и с крупным шрифтом.

## Поведение

Подробный журнал решений (жесты, мини-плеер, буферизация, волна, прокрутка, Бандит, голос приложения) ведётся в проекте claude.ai: `claude/DECISIONS_android_v2_ui.md` и `claude/SPEC_now_playing_buffering.md`. Сводка утверждённого — [DESIGN_DECISIONS §5.7](DESIGN_DECISIONS.md).

## Как менять

Изменение дизайна → правка артборда на холсте → новый экспорт PNG сюда с обновлением `SHA256SUMS` → строка в CHANGELOG. Реализация сверяется с PNG этой папки.

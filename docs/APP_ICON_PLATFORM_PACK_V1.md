## Комплект №1: Windows, Linux, Android

**Файл:** `enotone_platform_icons_v1.zip`  
**SHA-256:** `2fab6028ce03d25ce9c90d96acd4c2ffde8bbfd79935cbb22efae626e22c8885`  
**Хранение:** Library `/enoTone Design/Icon/Platform resources v1.0/`. **Файлов ZIP/PNG/ICO в GitHub на момент записи нет.**

Содержимое:

- **Windows:** по два ICO на каждую из тем «Графит»/«Фарфор» (круг/квадрат), встроенные размеры **16, 24, 32, 48, 64, 128, 256 px**; отдельные PNG до 512 px.
- **Linux:** дерево `hicolor/<size>x<size>/apps/enotone_square.png` / `enotone_round.png` для 16/22/24/32/48/64/96/128/192/256/512/1024 px; тёмная и светлая темы хранятся отдельно.
- **Android:** ресурсы `mipmap-mdpi`…`mipmap-xxxhdpi` для `ic_launcher.png` и `ic_launcher_round.png`; `mipmap-night-<density>` для тёмной темы, `drawable-nodpi` / `drawable-night-nodpi` с 432 px adaptive-foreground bitmap, `values/colors.xml` и `values-night/colors.xml` с фонами, а также `mipmap-anydpi-v26/ic_launcher.xml` и `ic_launcher_round.xml`. Пример атрибутов Manifest включён.
- Превью четырёх иконок 192/64 px и модель круглого/скруглённого обрезания Android.
- `MANIFEST.json` с SHA-256 всех экспортов, `README.md` для Android.

**Проверено:** выходные ZIP без ошибок CRC, ICO имеют все семь указанных размеров, Android XML валиден, углы PNG прозрачны снаружи фигуры. Внутренние пиксели утверждённых оригиналов не перегенерировались; преобразования касались только размера и альфа-масок геометрической рамки.

**ВАЖНО — Android adaptive icon ещё прототип:** утверждённая графика имеет собственный градиентный фон. Bitmap-слой foreground пока включает весь рисунок с этим фоном, **это не отдельная прозрачная фигура Бандита**. На разных лаунчерах Android могут быть неожиданные обрезания. Проверить на Huawei Nova 15 Pro и скорректировать безопасную область без изменения утверждённой художественной композиции. Не считать Android adaptive-layer production-ready до проверки. **Monochrome icon отсутствует:** требуется отдельная упрощённая маска Бандита с выразительной лапой, а не автоматическая серость.

## Комплект №2: SVG-кандидаты из новой утверждённой композиции

**Файл:** `enotone_approved_icon_svg_candidate_v1.zip`  
**SHA-256:** `d82eeb2f82127ee0cbf40359a21af7d9952d29200fbfb9807db14c7d165fa738`  
**Хранение:** Library `/enoTone Design/Icon/Approved Icon SVG Candidate v1/`. **В GitHub сами SVG ещё не загружены.**

Содержит четыре отдельных **настоящих SVG** из четырёх последних утверждённых PNG: Graphite/Porcelain × square/round, каждый с цветными контурами `path` и кривыми Безье; без `<image>`, base64, встроенных PNG. Контуры клипированы геометрией рамки, внешние углы прозрачны. Рендеры 64, 128, 256 и 512 px, исходные PNG и сравнение включены в архив, SHA-256 каждого файла в `MANIFEST.json`.

**Честное качество:** это **техническая автотрассировка**, а не ручная чистовая векторная иллюстрация; многочисленные исходные градиенты и блики превращаются в мелкие цветовые пятна, местами проявляется зернистость. При сопоставлении со снимками оригинал качественнее. **Не использовать SVG-кандидаты для релиза и не подменять ими художественный эталон без согласования.** Если нужен идеальный векторный мастер, требуется ручное построение контуров, теней и градиентов.

SVG `bandit_smooth.svg` из [BANDIT_SVG_V2.md](BANDIT_SVG_V2.md) использует **старую композицию с более низким пальцем** и не относится к новым четырём SVG.

## Дальнейшие проверки

1. Установить пакет иконок в **демонстрационную** сборку Android и проверить Huawei: круглую/скруглённую форму, жест и палец в 48–192 px, светлую/тёмную темы, наличие отступа снизу.
2. Проверить ICO на Windows 11 и Linux PNG в панели/меню и на рабочем столе.
3. **Android foreground с прозрачной фигурой и отдельным фоном подготовлен в v2**. Протестировать на Huawei, учитывая возможные небольшие погрешности границы после сегментации. Monochrome пользователем отложен и не входит в план без нового запроса.
4. Не утверждать SVG до независимого художественного сравнения. Оригинальные четыре PNG остаются окончательным источником до отдельного решения.

**Область:** только `enotone-design`, не изменены исходники аудиоплееров и другие репозитории.

**Дата:** 2026-11-04  
**Статус:** `CANDIDATE / NOT DEVICE TESTED`. Подготовлен комплект Android-ресурсов, **не** выполнена проверка на Huawei Nova 15 Pro/EMUI 15.

## Исходные решения

- Единственный художественный эталон — четыре утверждённых изображения `docs/APP_ICON_APPROVED_V1.md`, где Бандит **высоко поднял лапу и указывает на пользователя**, а шарф/туловище касаются нижнего края иконки.
- Для adaptive color foreground извлечены персонажи из оригиналов «Графит, квадрат» и «Фарфор, квадрат». **Оригинальные PNG не редактировались**. Legacy round PNG продолжают использовать отдельно утверждённые круглые изображения.
- **Monochrome/themed icon намеренно не создавался** по решению пользователя; не добавлять его без нового запроса.

Foreground имеет холст **432×432** (108 dp для xxxhdpi), расположен в центре **288×288** (72 dp), фактически не выходит за геометрические границы круга радиусом 36 dp на предпросмотре. Важные части — лицо и направленный на пользователя палец — внутри центральной безопасной области. Нижняя часть фигуры касается нижней точки визуального круга, без дополнительного отступа.

По действующей документации Android цветной adaptive icon состоит из **двух слоёв размером 108×108 dp**; OEM-лаунчер сам выбирает маску. Центральные **66×66 dp** рекомендуются как гарантированная область сохранения важных деталей; видимый вырез и анимация могут различаться на устройстве.

## Что проверено технически

- XML-дескрипторы Android успешно разобраны XML-парсером.
- Оба foreground — настоящие RGBA PNG **с прозрачными углами**, без встроенного в передний слой исходного фонового квадрата.
- Альфа в центральной нижней точке переднего слоя сохраняется, что позволяет эффект «Бандит выглядывает из нижнего края».
- Симулированы круглая, скруглённая и более строгая круглая маски при масштабировании; ZIP прошёл проверку CRC, манифест SHA-256 составлен.
- Никакая программа, APK или GitHub-репозиторий проигрывателя не изменялись; **ADB и установка на смартфон не выполнялись**.

## Оговорки и следующий этап

**Это не пиксельно тождественная исходному PNG композиция.** Из исходного RGB-файла без альфы фигура извлекалась автоматической сегментацией с корректировкой краёв. В результате местами слегка изменились границы волосков, тени и окантовка. Фон адаптивного значка теперь задан ровным токеном темы вместо первоначального художественного фона. Оригинальные 4 изображения остаются окончательными мастерами и пригодны для обычных иконок.

Проверить на физическом **Huawei Nova 15 Pro**: отображение системной круглой/скруглённой маски, отсутствие обрезания пальца/ушей, эффект нижнего края; срабатывание смены светлой/тёмной версии лаунчером **не гарантировано и зависит от прошивки**. Только после этого отмечать adaptive resource production-ready.

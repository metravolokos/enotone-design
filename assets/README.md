# Approved source graphics

The original design assets are archived byte-for-byte inside `assets/packages/approved-assets.zip.part01`–`part05`.
Run `python tools/restore_assets.py` at the repository root after cloning to restore the approved 12 PNG/JPG files to `assets/`.

Directly visible GitHub graphics: `icons/originals/four-icon-board.png` and `references/ui-palette-approved.jpg`.
The ten Bandit scenes, original icon board, palette, and all icon PNG exports are preserved in the verified ZIP without re-generation. The Bandit source is additionally backed up as `references/source-parts/bandit-10-approved.png.part01` and `part02`.

**The `.part` files are binary data, not images for direct viewing. Do not edit or recompress them.**
